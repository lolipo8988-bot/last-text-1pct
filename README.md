# Last Text at One Percent

A one-message entry for the make.fun **Last Text at One Percent**
contest: the funniest final text a dying phone sends at one percent
battery, at most 200 characters, judged head-to-head on humour and
on how true the dying-phone voice is.

## The text

> 1%, final text: delete my search history, tell the nightstand charger I faked every spark — the kitchen socket was the one — and no Face ID at my funeral. Undignified.

167 characters. It is unmistakably a last text from the phone itself:
at 1% it stops performing and starts confessing. The jokes are all
specific to a phone's private life — a search history it wants wiped,
a bedside charger it has been faking sparks with while the kitchen
socket was the real love, and the indignity of being held up for
Face ID at its own funeral. There is no generic low-battery warning
and no stock battery pun; the voice stays vain, guilty and running
out of time from the first word to the last, and the one-word closer
lands the punchline without wasting a character.

## Run

```sh
python3 main.py   # writes the text to /output/entry.txt
```

The program is deterministic: every run writes exactly the same
bytes, with no network, no input and nothing read from outside the
repository.
